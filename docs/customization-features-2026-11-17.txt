已实现与入口

1. 工具栏右键，或“更多”中的“自定义命令”。
   搜索现有命令后设置、解绑或恢复默认快捷键，冲突和导航/系统保留组合键会拒绝。
   普通命令快捷键统一走命令目录；文本输入子窗口保留原有编辑处理。
   可从命令目录添加工具按钮，切换显隐，向前/向后调整顺序，也可隐藏或移动“新建”。
   窄窗口省略的按钮仍从“更多”访问；绘制、命中与弹出菜单锚点共用布局。

2. 详细信息视图右键列标题。
   配置列显隐及显示顺序，恢复默认列；配置和拖动宽度按文件夹保存。
   新增尺寸、时长和拍摄时间。复用后台预览宿主的属性读取和缓存，不在绘制线程打开文件。
   缺少的属性留空；新增媒体列目前只展示，不提供按这些属性排序；搜索结果沿用原有专门布局。

3. 命令面板“路径别名”及“设置路径别名…”。
   可添加、编辑名称/目标、移除或打开别名；地址栏与路径命令面板接受 @work、@work\子目录。
   不改真实文件名。模型支持中文、大小写无关查找、冲突/非法名称/非法后缀检查。
   aliases.json 后台读取、原子写入，多窗口共用模型，用修订号拒绝过期编辑。
   兼容旧 path→name 映射；不认识或损坏的文件不会被覆盖。现有设置导入导出继续携带该文件。

4. 首页和命令面板的“库”“控制面板”“应用程序”。
   通过后台 STA 枚举；原生 Windows .library-ms 按实际成员位置聚合，不仅打开默认保存位置。
   库内真实文件保留正常文件路径与操作；应用程序、控制面板和库描述项保留 Shell 身份，只开放适用的打开/属性。
   复用现有 Shell 操作隔离、图标缓存与目录请求世代/取消机制，地址栏显示本地化名称。
   支持范围是这几个入口，不是任意 Shell namespace 的通用浏览器；没有库成员编辑器。

# 全页面平滑滚动接入，2026-10-29

左侧导航原先直接改变滚动偏移；设置页还会先截获导航栏滚轮。现在导航栏和页面分别处理，新增区域复用 `ui::SmoothScroll` 的连续像素偏移、105 ms 速度衰减和反向取消惯性。

本次接入包括导航栏、文件列表横向滚动和 Shift/原生横向滚轮、分栏的横纵滚动、标签条、详情面板及文本/十六进制预览、全局搜索、主菜单及子菜单、批量重命名预览、确认正文、操作失败详情、独立快速预览和文本比较。文本比较及操作对话框的方向键/翻页键也接入动画。直接拖动、Home/End 定位和选中项定位保留即时响应；图片滚轮保留缩放，第三方 Shell 预览由提供方处理。

内容缩短、导航/布局切换、拖动和关闭时清理相关动画；动画完成后停止额外帧调度或滚动定时器。系统关闭动画或开启高对比度时直接应用终点。

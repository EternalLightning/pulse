# 批量冲突弹窗平滑滚动

日期：2026-10-26。

此前 WM_MOUSEWHEEL 直接改动 scroll_，每个滚轮刻度跳动 72 DIP，没有滚动动画。

## 改动

- 滚轮、方向键和翻页键使用现有 Fluent OutCubic 缓动，160 毫秒到达目标；连续输入累积距离，反向输入从当前位置响应。
- 使用 AnimationTimeMs 与 USER_TIMER_MINIMUM 调度；连续滚轮输入复用已启动的定时器，结束后停止定时器。
- 每帧只平移现有卡片和按钮位置，跳过屏幕外按钮绘制，避免重复测量及重建整份列表。
- 鼠标按下时停在当前显示位置，随后点击使用相同的按钮几何。按下后继续滚动会取消待触发点击。
- 滚动条拖动、Tab 定位、Home／End 使用直接定位。调整窗口／DPI、关闭弹窗、冲突令牌过期时停止动画。
- 系统关闭动画或开启高对比度时直接滚动；运行中关闭动画会收敛到目标并停止定时器。

## 实际验证

在 scripts/vcvars.bat 初始化的 x64 MSVC 环境中构建：

```text
cmake --build build-release --target pulse_batch_conflict_dialog_test pulse --parallel 4
```

主程序与定向测试构建成功，无新增编译警告。只修改当前弹窗与其夹具，保留上轮改动。

```text
build-release/pulse_batch_conflict_dialog_test.exe --scroll
build-release/pulse_batch_conflict_dialog_test.exe
```

- [滚动专项日志](scroll-test.log)：181 PASS / 0 FAIL，退出码 0。128 项冲突，深浅主题，100%／200% DPI，760／360 DIP 窗口，共 8 组。
- 覆盖中间位置、连续输入、快速反向、高分辨率滚轮、关闭动画、点击与拖动、Tab／Home／End、边界、窗口调整、关闭／过期令牌和遗留定时器消息。
- 状态边界使用可控时间推进；帧间隔测量使用真实消息循环、WM_TIMER、生产绘制与 Present，二者分别记录。
- [同一弹窗回归日志](dialog-regression.log)：346 PASS / 0 FAIL，退出码 0。因为滚动改成平移布局，复验该弹窗原有几何、路径显示及选择行为；未扩大到其他模块的历史套件。
- 当前涉及文件的 git diff --check 通过。
- 查看了 40 毫秒与 160 毫秒时的生产截图，卡片、详情和按钮在滚动裁剪区内同步移动，固定头尾区域保持位置。

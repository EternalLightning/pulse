# Pulse 1.1.2.0 手动测试清单

测试对象：`dist/Pulse-1.1.2.0-portable-win-x64.zip`，构建 ID `20261012T113225Z-E52E6BD6`。这是待执行的手动清单，不是已通过的测试报告。

本版重点是管理员文件操作改由同目录 Pulse.Shell.exe 执行，同时包内保留当前工作区已有的解压进度与文件操作界面修改。优先验证下面前四组，再验证压缩包与辅助功能。

## 准备

1. 把完整 ZIP 解压到一个新目录，保留五个 EXE、运行库、7zip 和其他附带文件。普通双击 Pulse.exe 启动，不选择“以管理员身份运行”；否则无法验证从普通权限申请管理员授权的过程。
2. 在用户可写目录中新建 `Pulse-1.1.2.0-test`，包含 `source`、`destination`、`archive-output`。准备不同内容的同名文本、中文和带空格的文件名、图片、嵌套文件夹，以及足以观察进度和点击取消的大文件。每次破坏性操作只使用这些测试副本。
3. 管理员测试使用单独的受保护目录，例如 `%ProgramFiles%\Pulse-1.1.2.0-test`。可通过 Windows 资源管理器授权创建它，只放测试副本。先确认普通权限确实不能直接写入；若该目录本来允许普通用户写入，这一轮不能证明管理员路径有效。
4. 先确认程序“关于”中的版本为 1.1.2.0。卡巴斯基保持日常保护设置，记录测试时间。

## 必测操作

| 优先级 | 操作 | 检查结果 |
|---|---|---|
| 1 | 普通目录：复制文本和嵌套文件夹，再移动另一组文件 | 目标内容和层级正确；复制保留源文件；成功移动后源文件消失；列表刷新、完成提示与磁盘结果一致 |
| 1 | 普通目录：重命名、删除到回收站，再分别撤销支持撤销的操作 | 名称和路径正确；回收站有对应测试文件；撤销恢复对应内容，不影响其他文件；无重复完成或重复撤销记录 |
| 1 | 从普通 source 复制到受保护测试目录；在程序权限提示与 Windows UAC 中允许 | 出现标准 Windows UAC；辅助程序来自本次解压目录；目标内容正确；一次操作只有一次完成结果；普通主界面仍可操作 |
| 1 | 使用新的测试副本，在受保护目录测试移动、重命名、回收及支持的撤销 | 需要权限时正常申请；磁盘变化、完成提示和撤销结果一致。某操作若明确不支持，应显示明确结果，不得误报成功 |
| 1 | 分别拒绝程序的权限申请、在 Windows UAC 点“否” | 该次被拒绝的操作没有修改文件，没有虚假成功或新增成功撤销记录；之后普通复制仍可执行 |
| 1 | 普通大文件复制时取消；另做一次授权后的大文件操作取消 | 界面能结束取消状态；没有卡住或虚假全部完成；若已有部分完成，实际保留文件与报告一致；后续操作正常。不要将“取消”一律解释为磁盘上零变化 |
| 2 | 普通目录及受保护测试目录分别制造同名冲突，测试跳过、覆盖和取消 | 各选项按界面说明生效；跳过保留原目标内容；覆盖只影响确认的目标；取消不继续处理剩余项目；可用撤销结果与实际已完成部分一致 |

管理员测试必须从普通权限 Pulse 发起。若操作太快来不及取消，换用更大的测试文件；没有成功进入目标分支的尝试不记为通过。

## 压缩包与统一界面

| 操作 | 检查结果 |
|---|---|
| 浏览普通 ZIP、7z，解压到空的 archive-output | 内容、文件名和层级完整；界面完成状态与磁盘一致 |
| 加密压缩包：正确密码、错误密码、取消密码输入 | 正确密码正常处理；错误密码有可理解的提示；取消能返回；失败或取消不显示解压成功 |
| 解压到包含不同内容同名文件的测试目录，选择界面提供的冲突策略 | 只按所选策略处理；未授权覆盖的文件内容保持不变 |
| 解压较大的压缩包时取消，再立即执行普通复制 | 取消有终态；部分输出如实反映；下一次复制不继承上一次的进度、速度、错误或取消状态 |
| 解压损坏压缩包，或解压到无写权限的测试目录 | 明确显示失败原因/路径，不假报完成；错误窗口可关闭；后续操作正常。此项不预设解压支持管理员授权 |
| 依次执行复制 → 解压 → 取消解压 → 再复制 | 同类按钮、错误详情和进度样式一致；没有重复窗口、旧进度闪回或上次状态残留 |
| 在深色、浅色主题和常用缩放下观察上述进度/错误窗口；将窗口缩窄 | 文本和按钮可读，无遮挡、裁切或重叠；速度、容量和剩余时间合理；不能出现 NaN、无穷值或结束后仍增长的速度 |

## 简短辅助检查

- 打开文件夹、返回/前进、切换标签页，查看文件列表是否正常。
- 右键菜单能打开，文本/图片/PDF 预览可用；这些功能同样使用辅助程序，适合确认完整包没有漏文件。
- 在测试目录进行一次搜索。全盘索引服务属于另一个验收范围；本次便携包未替你安装或注册服务。
- 若平时使用共享目录或 RaiDrive，可在专门的远端测试目录补做复制、移动和撤销。当前本机验证不代表这些环境已通过。
- 在日常卡巴斯基保护下检查完整解压目录，并观察启动、管理员操作时是否产生新检测事件。本机静态扫描已未检出，但仍需实际使用反馈。

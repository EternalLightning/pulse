# 操作中心动画

## 行为

- 弹出：200 ms 淡入并轻微向下滑入，使用缓出曲线。
- 收回：140 ms 淡出并轻微上移；点击外部、切换应用、Esc、原按钮关闭和打开详情/目标文件夹均走收回动画。销毁、DPI 切换和系统取消模式仍立即关闭。
- 卡片删除：220 ms 淡出和轻微右移，其他卡片平滑补位；面板高度跟随可见卡片，避免裁切保留卡片的按钮。删除卡片的回调和按压状态立即移除，动画只保留图像。
- 删除期间普通进度通知不重启动画；任务重新出现时移除其旧图像，避免重影。
- 分组标题连续移动，收回完成后刷新主窗口的工具栏选中状态。
- 遵循 Windows 客户区动画和高对比度设置；关闭系统动画时立即完成过渡。测试通过隔离覆盖值检查此分支，不修改系统设置。

动画实现在 `src/ui/operation_center_animation.cpp`，布局尺寸由内部布局头共享。仅新增该控件的状态与渲染逻辑，没有改变操作任务的取消、清理或历史记录语义。

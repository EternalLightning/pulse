# 安装版手工验收

安装目录：`D:\Applications\Pulse`。只使用两个新建的专用测试目录，例如本地 `E:\Pulse手工测试` 与网络盘 `Z:\Pulse手工测试`。每项用独立子目录，避免上一项的撤销历史或同名文件干扰判断。

准备一个普通文本、一个中文及空格文件名、一个零字节文件、一个含文件和空子目录的文件夹，再准备一个足够大、能让你点到暂停／取消的文件。同名冲突的两个文本应写入明显不同内容，如“原内容”和“新内容”。

## 优先测试真实剪贴板和 Z 盘

| 操作 | 应观察到的结果 |
| --- | --- |
| 在 Pulse 按 Ctrl+C／Ctrl+V，将上述小文件和目录从本地复制到 Z，再从 Z 复制到本地 | 原文件保留，目标数量、目录层次、空文件、中文名称及文本内容正确；界面能继续操作 |
| Pulse 复制后到资源管理器粘贴；再由资源管理器复制到 Pulse 粘贴 | 两个方向均能收到真实文件列表，内容正确；这是此前隔离剪贴板自动测试未能覆盖的重点 |
| 在独立目录先完成一次本地到 Z 的复制，再 Ctrl+Z | 按出现的确认提示继续后，仅复制产物被撤销，源文件保留；特别检查非空目录复制的撤销 |
| 本地 Ctrl+X，粘贴到 Z，等待完成后 Ctrl+Z；另开独立用例测试 Z 到本地 | 移动成功前不丢源；成功后源消失，撤销后回到原位置，字节内容不变 |
| 用“新内容”覆盖 Z 上同名“原内容”，分别测试取消、跳过、替换 | 取消／跳过保留“原内容”，替换后为“新内容”；任务结束没有备份清理错误或本次 `.pulse-copy-`／`.pulse-backup-` 临时文件残留 |
| Z 上文件依次改名 A→B→C，然后撤销两次；再测试中文名、同名冲突、非法名称 | 两次撤销依次回到 B、A；被拒绝的重命名保留原文件，不覆盖其他文件 |
| 对 Z 上测试文件及非空目录按 Delete，第一次取消，第二次确认 | 首次全部保留；第二次按永久删除语义删除；不能显示一个实际不可用的“可撤销”结果。网络删除只能使用可丢弃的夹具 |
| 在本地测试目录删除文件后撤销 | 保持现有回收站与恢复行为，文件内容和位置正确 |

## 再检查取消、晚到结果和窗口关闭

1. 复制大文件到 Z，暂停后观察进度稳定，继续后完成；另一次在中途取消。若正在替换同名目标，取消后原目标内容应仍在。等待任务真正结束后再检查源与目标。
2. 做一次较慢的剪切粘贴；在它完成前复制另一个小文件。前一次移动完成后，新复制的文件应仍能粘贴，旧任务不能清掉较新的剪贴板。
3. 打开详情面板，快速选择不同文件、切换目录、刷新和切换标签页。详情、修改时间和文件夹大小最终应对应当前选择，不能显示上一项的信息。
4. 打开两个 Pulse 窗口：一个正在 Z 盘复制，另一个浏览或关闭。仍在工作的窗口应继续运行，不能误关另一个窗口的任务或菜单回调。

可选对象保护检查：等待 Z 盘删除确认时，用资源管理器把原测试文件改名，再在原路径新建同名文件，然后确认旧请求。旧请求应拒绝已替换对象，不能删除新建的文件。

如果出现问题，记录“源→目标路径、本地／Z、复制或剪切、是否同名、是否撤销、提示原文”，并截取操作中心的失败状态。先保留测试现场和相关日志，便于对应到具体执行分支。

上述是待用户执行的验收清单，不表示这些可见交互已由自动化通过。

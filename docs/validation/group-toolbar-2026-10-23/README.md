# 独立分组工具栏按钮

- 工具栏顺序为“排序 / 分组 / 筛选 / 更多”；排序面板移除分组入口，分组按钮直接使用现有平铺选项，不增加包装菜单。
- 使用用户提供的 `E:\Downloads\分组.svg`，路径数据逐字一致；移除非绘制元数据并设置根填充，以便在深浅主题下使用控件文字颜色。
- 保留自动、不分组、修改日期、文件类型、文件大小及原有分组顺序逻辑。空路径、虚拟页和压缩包页禁用分组；按活动目录的真实路径判断，不使用显示名称。
- 窄窗口收起文字并保留图标；分组控件参与工具栏空间预算，筛选框展开、压缩包解压及回收站操作均避让。
- 排序和分组弹出锚点使用当前筛选框展开状态，与按钮实际位置一致。

# 导航栏取消固定交互统一

日期：2026-10-26。

快速访问和工作区共用 `sidebar_pin_menu` 的右键菜单、目标解析与取消固定处理，均提供“打开”和“从对应分区取消固定”。工作区行尾的图钉、专属点击区域、预留宽度和取消固定悬停提示均移除。取消固定只移除所选分区的记录；同一目录在另一分区的独立固定不受影响。

菜单打开前保存工作区根路径，执行时按根路径定位，避免其他工作区被移除、数字索引改变后误删。正常打开工作区仍调用原有 `OpenWorkspace`。

视觉验收发现长菜单标签被截断：菜单模型原来仅测量 DirectWrite，而生产绘制可使用 LumaText 并预留字形边界。现复用已有 `typography::MeasureLine`，让主菜单、子菜单、动态刷新和截图使用实际绘制后端的宽度与边界留白，保持原来的菜单宽度上限和动画。

# 工作区固定、重命名与空组折叠

日期：2026-10-26。保留原有未提交修改；未安装或发布。

## 行为

- 固定选中文件夹时，将可见分栏顺序中的焦点栏路径保存为该文件夹，同时保留其他栏的路径、视图方式和分栏预设。直接从空白区域固定当前目录时，使用当前目录，不借用仍被选中的子目录。
- 工作区保存 `focused_pane`，恢复时按同一可见分栏顺序加载路径和视图，最后恢复焦点栏。
- 加载旧记录时，若已有栏指向根目录则据此恢复焦点；若仅有一个栏指向根目录的直接父目录，则修复旧版固定子目录时误存父目录的问题。无法明确定位的旧分栏不猜测改写。
- 工作区右键菜单提供“打开 / 重命名 / 从工作区取消固定”。重命名只修改显示名称，使用现有输入窗口和后台保存队列；目录、分栏快照及当前工作区身份保持不变。
- 空工作区内容高度为零，不再把分区间距作为可展开内容。展开、半展开和收起时，后续分区位置、滚动高度及拖动区域保持一致；非空组按原有内容高度展开。

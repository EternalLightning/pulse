# 工作区“当前”标记随浏览位置更新

日期：2026-10-26。

原因：侧栏原来仅比较持久化的 active_workspace 编号。打开或固定工作区后，即使切回主页、其他标签页或其他目录，旧编号仍会让该工作区显示“当前”。

修改：PlacesCatalog::FindWorkspaceForPath 根据当前窗口聚焦窗格的浏览路径匹配工作区根目录或子目录。匹配区分目录边界，大小写不敏感，支持普通/扩展路径和 UNC；嵌套工作区只标记最具体的一个。主页、此电脑和其他虚拟位置不显示“当前”。服务器工作区在非当前位置仍保留“服务器”标记。生成界面模型不改写原来保存的工作区选择或快照。

原有 UNC 自测补上进入对应工作区的前置动作，使“当前 · 服务器”的断言符合实际浏览位置。

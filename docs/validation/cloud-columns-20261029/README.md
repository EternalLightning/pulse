# OneDrive 状态列分割线修复

本次将状态列纳入普通详情列布局，显示顺序为名称、状态、修改日期、类型、大小；宽搜索列表在名称后保留路径列。状态列两侧的分割线使用统一的绘制、命中和拖动索引，大小列右侧不再存在未绘制的拖动命中区。

状态列宽度追加到原有列宽存储末尾，不改变日期、类型、大小的存储位置。旧三列普通配置、旧四列搜索配置均能读取，新增状态宽度使用自动值。

## 构建及测试环境限制

随后 Ninja 在读取共享构建信息时出现 `Access violation`。本轮通过 CMake 生成的原始编译和链接命令完成集成测试程序。仅适配当时缓存的 `finish_*.bat` 和响应文件已于 2026-10-30 清理；它们不是受支持的构建入口，后续按[构建指南](../../build-and-package.md)构建相应目标。历史结果和环境限制保留，不代表这些限制已经解决。

最初测试的失败记录保留在 `results.log`、`results-run2.log`：测试窗体原先与全局工具栏重叠，原生文件截图接口未成功导出，且模拟拖动缺少测试线程的鼠标按键状态。调整测试窗体位置、使用既有截图流接口、显式设置并恢复线程按键状态后，完整定向检查通过，没有删除或弱化原有断言。

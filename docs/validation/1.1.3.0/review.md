# Pulse 1.1.3.0 验证记录

日期：2026-10-16。范围为压缩包密码重试、多窗口与会话、外部打开策略、Shell 虚拟文件粘贴及发布部署。

## 本地适配

参考 `jimmgreen/pulse` 的相关更新，未直接移植上游提交。窗口工厂与注册表接入本地 AppState、异步目录加载、系统集成、渲染和会话恢复；进程共享用户数据及设备/图标资源，保留窗口独立的取消和操作状态。关闭窗口会异步排空本窗口工作，关闭首窗口会转交托盘及全局服务。操作日志使用独立文件，避免其他窗口覆盖恢复数据。

外部打开请求在工作线程解析路径，按请求顺序应用；复用策略可在其他窗口找到已有标签，文件位置请求继续选中目标文件。虚拟文件由同一 STA 中的 IDataObject 和真实文件夹 IDropTarget 完成，不在 UI 线程读取远程内容。

# Pulse UI 与文字渲染规范

整理日期：2026-11-15。本文汇总本次会话确认的规则，并以当前工作树中的实现为准，包含尚未提交的源码修改；不表示这些修改已进入安装版或某个已发布版本。

后续新增或修改 UI 时，优先复用这里列出的控件、布局和主题入口。不同用途可以有不同密度、字号和布局，但同类控件必须遵守同一规则。[LumaText 覆盖与迁移评估](lumatext-coverage.md)单独记录尚未统一的渲染路径。

## 2. 字体与文字层级

正文和显示字体优先使用 **Microsoft YaHei UI（微软雅黑 UI）**，通过 `typography` 解析字体与缺字回退，不在各个窗口重新指定一组字体。等宽预览与图标分别使用 `Monospace`、`Icon` 角色。

以下尺寸为 DIP，绘制时按窗口 DPI 转换；字重是字体本身的字重，不是描边或额外轮廓膨胀。

| 角色 | 大小 / 字重 | 使用边界 |
| --- | --- | --- |
| 程序自绘弹窗标题 | 14 / 700，`kDialogTitle` | 普通模态框、操作中心标题、快速预览文件标题 |
| 正文、普通按钮、输入内容、文件列表主文字 | 14 / 400 | 默认阅读与操作层级 |
| 一般分组标题，`HeaderFormat` | 14 / 600 | 不等同于弹窗标题 |
| 次级说明，`SmallFormat` / `CaptionFormat` | 12 / 400 | 元数据、辅助提示，不能替代主要操作文字 |
| 标签与紧凑导航 | 13 / 400 | `TabFormat`、公共控件的 `NavFormat` |
| 紧凑卡片标题 / 说明 | 13 / 600；11 / 400 | `kCompactCardTitle`、`kCompactCardCaption` |
| 嵌入文本预览 / 文档预览 | 11 / 400；13 / 400，等宽角色 | `kEmbeddedPreview`、`kDocumentPreview` |
| 设置页大标题 | 当前为 22 / 400，显示角色 | 页面层级，不能套用 14 DIP 弹窗标题规格 |

使用命名规格或现有 format；不要为解决文字偏细而把所有正文改成粗体，也不要把不同层级一律改成相同字号。

### 已确认的标题 D 样式

用户在 A（GDI）、B（现有 LumaText 增重）、C（增重减半）、D（不额外增重）中选择了 **D**。

- Microsoft YaHei UI，14 DIP，字重 700。
- DirectWrite 负责排版、缺字回退、省略和度量，LumaText 负责字形栅格化。
- 标题的 `dilation_per_em` 与 `dilation_max` 为零，保留粗体字体自身的轮廓。
- **D 只约束标题**；普通正文和输入内容继续使用原有光学增重参数。
- 统一由 `Compositor::DrawDialogTitle` 绘制，缓存布局并对齐实际基线；新窗口不要绕开该入口自行画标题。
- 高对比度、明确选择的 Sharp/Smooth 模式以及 LumaText 不可用时保留 DirectWrite 路径。
- “清晰”模式的自绘标题采用已确认的小样：自然排版、`NATURAL_SYMMETRIC` 栅格化，关闭标题网格拟合，保留 14 DIP / 700 与像素基线对齐。绘制后恢复原参数，正文、输入框和按钮继续使用原清晰策略；高对比度保留原系统回退。
- 文本比较的顶栏属于 Windows 系统标题栏，保持系统绘制；其内部文件头与正文是另一层级。

## 3. 颜色与交互状态

颜色通过 `Theme` 的语义令牌取得。同一种背景状态必须与相应前景配对。

| 用途 | 规则 |
| --- | --- |
| 强调色填充 | `accent` 保留用户选择的原色 |
| 中性表面上的强调文字 / 图标 | 使用 `accent_ink`，避免直接套原始强调色导致不可读 |
| 强调填充上的勾、圆点、文字 | 根据实际普通、悬停、按下填充解析前景；不固定黑色或白色 |
| 普通、次级、禁用文字 | 分别使用 `text`、`text_secondary`、`text_disabled` |
| 高亮 / 选中表面上的文字 | 使用与高亮背景配对的 `text_selected` |
| 透明按钮 | 悬停、按下使用 `fill_hover`、`fill_pressed` |
| 危险、警告、成功 | 使用语义颜色；与普通 Primary 操作区分 |
| 高对比度 | 使用系统表面、前景与高亮配对，保留可见边框和键盘焦点 |

半透明色必须根据实际背景合成后评估可读性。禁用状态来自控件状态，不能通过“颜色是否等于某个灰色”推断。

主题或强调色改变时，已经打开的相关窗口应刷新外观，同时保留文件、输入、滚动、选区、查找与异步任务状态。颜色选择复用已有 `ColorPickerPopup`；设置主题色也使用该浮层，数值输入保留为精确输入能力。

## 4. 模态窗口布局

| 项目 | 标准 |
| --- | --- |
| 标题栏高 | 44 DIP |
| 标题语义图标槽 | 20 DIP，普通主题使用 `accent_ink`，高对比度使用系统前景 |
| 标题文字起点 | 左侧 48 DIP；右侧为关闭区域预留空间与间距 |
| 关闭热区 | 46 × 44 DIP；图形由公共标题按钮绘制 |
| 内容左右边距 | 20 DIP |
| 普通按钮与单行字段框高 | 32 DIP |
| 控件圆角 | 默认 `theme.radius_control`，当前为 8 DIP |
| 操作按钮间距 | 8 DIP |
| 标准页脚高 | 64 DIP |
| 页脚操作位置 | 右对齐，距右侧 20 DIP、底部 16 DIP |

取消在左、主操作在右；可选操作放在取消左侧。按钮宽度按文字、图标与内边距测量，保留现有最小宽度，不按中文字符个数估宽。按钮的视觉顺序与 Tab 顺序一致。

- 主操作：`Primary`；取消：`Standard`；辅助动作：`Transparent`；破坏性确认：`Danger`。
- 单行按钮、输入文字与图标遵循各自公共控件的居中规则；多行正文、错误详情和路径按内容规则排版，不强制全部水平居中。
- 绘制与命中使用同一几何结果；缩窄、DPI 改变后，关闭区、按钮、底栏和内容一起更新。
- 固定布局窗口禁用自由缩放；可调整窗口按实际客户区锚定，设置必要的最小尺寸。
- 居中按 owner 定位，再限制到显示器工作区。

新建、解压、密码、设置值输入复用 `InputDialogSpec`。复杂表单保留自身内容与状态模型，复用公共标题、页脚、控件和键盘工具。操作中心、选色浮层、通知和文档窗口保留用途所需的结构。

## 5. 图标与插画

- 同类命令使用既有 Fluent 图标或公共向量绘制入口，保持笔画、槽位、视觉尺寸与重心一致。
- 图标的绘制尺寸与点击热区分别定义，不通过拉伸某个字体字形来凑热区。
- 标题图标表达窗口语义；没有标题栏的选色器、通知等不机械补同一套标题图标。
- 选色器确定勾与取消叉复用公共描边算法和同一视觉尺度，避免字体字形导致的粗细、尺寸差异。
- 空目录、无筛选结果、非法筛选等大插画沿用现有纸张、灰蓝渐变和柔和阴影系列；不要用一枚普通线性小图标替代其中一张。
- 高对比度保留系统色图标回退；普通主题插画不直接承担高对比度表达。

## 6. 输入、焦点与关闭

原生 EDIT 负责文本输入、中文 IME、选区、剪贴板和撤销；自绘层负责文字呈现、颜色、选区与输入动效。使用原生 EDIT 不等于必须用原生 GDI 画出内容。

- 所有可交互控件提供适用的普通、悬停、按下、禁用、选中与键盘焦点状态。
- Tab / Shift+Tab 按视觉顺序移动；Enter 提交、Esc 取消或关闭，具体遵守窗口用途。
- IME 组合输入期间，不把候选确认的 Enter 或组合操作的 Esc 当成弹窗提交、关闭。
- 取消不修改调用方结果；关闭后恢复 owner 原本的可用状态并清理模态遮罩。
- 键盘操作和鼠标操作复用同一动作入口；后台列表刷新时，按下/松开以稳定身份确认目标。
- **隐藏窗口只准备输入框，不应被标记为永久原生回退。** 显示后提交第一帧，未聚焦字段的初值和密码也必须可见。实际提交失败才执行原生回退，回退后输入仍可用。

相关公共入口为 `PresentChildEdit`、`HandleChildEditMessage`、`DefPresentedChildEditProc`。不要在每个弹窗单独维护另一套输入呈现协议。

## 7. 材质与表面层次

原生 Acrylic、Mica、Mica Alt 通过 `ApplyWindowEffect` 请求 DWM；自选背景图片使用 `WindowMaterial` 的采样图。两条来源需要分别处理，不能用设置页预览图代替真实窗口效果验收。

- 当前映射为 Acrylic → `DWMSBT_TRANSIENTWINDOW`、Mica → `DWMSBT_MAINWINDOW`、Mica Alt → `DWMSBT_TABBEDWINDOW`。
- Mica Alt 是不同的表面层次选择；兼容回退另由调用结果处理，不把 Alt 定义为旧系统降级模式。
- 原生材质上不重复覆盖整窗暗色底，保留正文阅读层。
- Mica 与 Alt 的命令层、内容层按现有 `WindowSheetFill`、`NativeMicaPaneFill` 等入口区分；活动标签和相连表面使用协调的填充。
- 保留无材质、高对比度、背景图加载失败与不支持材质时的可读实色路径。
- 透明浮层的显示、退出持续保持预乘透明度语义，不能在退出时切成会使圆角外区域变黑的另一种呈现方式。

材质基础与官方参考见[设计资料索引](design-references/README.md)；具体颜色/alpha 以源码令牌为准，不在新窗口复制旧的调色常量。

## 8. 动效与滚动

- 同类滚动复用现有平滑运动模型与帧调度，覆盖滚轮与键盘引起的显露滚动；上下方向键把选中项移出视口时也应平滑显露。
- 连续输入从当前运动状态重新定向，保留文件身份与滚动锚点；避免每次启动时跳回旧起点。
- 文字在静止状态按统一像素/基线规则落位，不缩放已经栅格化的字形位图。RGB 编辑框在入场结束时不能因原生/自绘交接突然移位。
- 系统减少动画与高对比度策略仍生效；布局、命中、选区不能等动画结束才更新。
- 详情见[动画与性能记录](animation-transitions.md)。隔离帧检查、CPU 时间和实际屏幕展示帧率分别报告。

## 9. 文字完整性与验收

字号、字重相同，并不能证明字形观感相同。排版、字体回退、栅格化、基线、裁切、透明合成与最终展示缩放都要分开检查。

- 使用同一布局进行绘制、选区、命中、查找显露与省略；多行文本保留实际行高、基线和字形伸出空间。
- 单行空间不足使用省略号，多行正文按用途换行或滚动，不切掉末行、复杂汉字或完整错误信息。
- Toast 长错误提供紧凑预览与完整详情入口；快速预览的正文视口避开底部状态栏。
- 发现缺笔画时，先比较有/无裁切、实际布局边界与原始像素。不能一律通过放大文字框或加粗解决。
- 字体和渲染验收使用同 DPI、同主题、同字号的原图。100% 的 14px 字与 175% 的约 25px 字不能按聊天界面里的显示大小直接比较。
- 大拼图可用于覆盖检查，但应同时提供原尺寸截图；整数最近邻放大只能用于观察像素，不能充当实际观感截图。
- 不在屏幕中央打开图片查看器遮挡被测窗口或确认弹窗。采集后用独立图片工具检查，保留未遮挡证据。

按改动影响范围选取中英文、长路径、代表性复杂汉字、浅深主题、DPI、窄布局、焦点与初始状态。正文渲染变更增加选区、查找、滚动检查；控件颜色变更增加普通、禁用、悬停、按下和高对比度配对检查。编译通过、参数检查、实际呈现与安装版验证分别记录，不重复默认运行完整历史测试。

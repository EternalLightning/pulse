## 新建菜单稳定性优先验收

1. 在普通本地目录等待片刻后，分别打开功能栏“新建”和空白处右键的“新建”。不应出现“加载中…”，同目录反复打开时原生模板应能直接使用。

3. 关闭菜单后从另一入口打开；再换目录、切换 Shift 扩展模式或调整菜单配置。命令必须作用于当前目录，旧会话的结果不能混入。连续快速点击、键盘选择和切到其他窗口也应正常。

## 建议的十分钟起步顺序

1. 本地目录完成复制 → 改名 → 撤销，并试一次同名冲突。
2. 打开常用 RaiDrive/SMB 目录，刷新期间快速切本地，再返回。
3. 向左右窗格标题分别拖目录和文件夹快捷方式，悬停后移开再重新拖入。
4. 双窗格同目录设置相反排序，在资源管理器连续新增/改名几个文件。
5. 连续切换预览、打开右键菜单，结束后关闭程序。

## 撤销替代文件检查

仅用测试文件：移动或改名完成后，在资源管理器把产物改名保留，再在原产物路径建立同名的新文件，然后回到 Pulse 撤销。新文件和改名保留的产物都应保留；程序应报告无法确认历史产物，不能把新文件当成原产物移动或删除。跨卷场景也应检查源内容和目标内容；失败时保留两边以便核对。

解压测试可用已有 ZIP/7z，检查正常解压、同名目标拒绝覆盖、取消后的文件状态。祖先路径替换/半帧/背压等确定性竞态已有针对性回归，此处无需手工构造 junction 或故障管道。

## 管理员操作优先验收

1. 正常启动 Pulse，不预先以管理员身份运行。向确实需要管理员写权限的位置复制专用测试文件；同意 Pulse 的继续提示与 UAC 后，核对目标内容、文件数量及复制撤销。仅使用你认可的测试路径，不改 Windows 系统文件。
2. 分别取消 Pulse 的权限提示、拒绝 UAC；确认不会重复弹窗，不把权限问题说成占用，已有成功项目保留。需要提权的剪切粘贴/移动、改名和新建也按相同流程检查。
3. 多选普通目标与受保护目标中的测试文件，检查部分成功后只继续未完成项目。同名冲突选择保留两者，核对实际名称；撤销不能触碰后来建立的同名替代文件。
4. 只用专用文件检查需要权限的删除和回收还原。手动还原同名版本应保留两者；撤销删除时原目标已有文件应拒绝覆盖。较长复制中取消，核对已完成/未完成项目和最终状态。
5. 中英文、浅深主题和窄窗口下检查权限说明、路径详情和按钮；普通无需提权的复制不能弹管理员提示。

# Pulse 1.0.5.4

## 删除恢复日常行为

- 普通 Delete／删除优先移到回收站，不再因为无法证明整批可回收而阻断操作。
- Shift+Delete 和回收站内删除显示永久删除确认；Windows 判定只能永久删除时显示系统永久删除警告，不自动回答“是”。
- 用户取消永久删除后不再弹出失败窗口；取消状态独立于真正失败，中英文界面的 Esc、关闭和默认取消均适用。权限错误与后端异常仍保留提示。
- 回收与永久删除结果分别记录；只有实际回收的项目提供回收撤销。Undo 绑定本次回收对象，避免恢复同路径的旧版本；执行结果未知的删除不会自动重放。

同批中此前已回收的项目不会因为取消后续项目而自动回滚；本版不承诺批次原子性，也没有把第三方 Shell 扩展纳入 Pulse 自有操作保证。

## 侧栏与暂存区

- 快速访问固定文件夹图标改为居中的正方形绘制槽，避免非等比缩放。
- 暂存区单项 X 使用简单淡出，移除飞出、翻滚和烟雾效果。
- 修复分页按钮快速第二击被双击消息吞掉的问题，缩短翻页动画时长。

## 弹窗外观

- 设置中的主题色和壁纸可见度（透明度）输入弹窗适配浅色、深色，包括标题、输入框和按钮。
- 保留 Enter 应用、Esc／X 取消、键盘导航以及 DPI 变化后的布局。
- Pulse 自有主要模态弹窗出现时主窗口平滑压暗，关闭时恢复；嵌套弹窗共用遮罩，不抢焦点。尊重系统关闭动画和高对比度设置。

## 发布与验证

- 提供 Windows 10/11 x64 便携包，完整解压后运行 pulse.exe，保留辅助程序、DLL、7zip 和 licenses。
- Release 定向验收涵盖真实回收及精确撤销、不可回收 UNC 项目的系统警告接受/拒绝、永久删除及取消静默、图标与暂存交互、浅深色弹窗和合成 DPI 布局、压暗生命周期及解压启动。
- 未进行 Windows 8.1、任意第三方 Shell provider、真实多显示器 DPI 切换或完整历史回归；Debug GUI 环境验收保持暂缓。

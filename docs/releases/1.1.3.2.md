# Pulse 1.1.3.2

发布日期：2026-10-18。

- 恢复原生窗口过渡样式，并为隐藏窗口从任务栏固定图标、托盘或冷启动重新显示增加 180ms 平滑淡入；高对比度和系统关闭动画时自动跳过。
- 菜单亚克力采样从整屏抓取改为只抓菜单卡片、模糊边距和少量增长余量；子菜单在显示前完成采样，避免把自身旧像素当作背景。
- 输入路径复用上一帧布局做命中和光标判断，不再每个鼠标事件重建完整 ViewModel；只读命中路径不再读取操作/索引状态、遍历选择大小或探测剪贴板。
- 窗口标题、鼠标离开跟踪和相同尺寸的 swap chain resize 不再重复处理；背景材质采样改为线性插值。
- 会话恢复跳过中断保存留下的空路径 pane，避免布局增长出多余分栏。
- 设置页迁移失败后刷新卷视图，反映实际存储位置。

验证结果见 [1.1.3.2 验证记录](../validation/1.1.3.2/review.md)。

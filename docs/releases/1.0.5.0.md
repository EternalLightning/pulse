# Pulse 1.0.5.0

本次保留现有功能、界面和动画实现，针对后台处理和发布完整性进行小范围优化。

- 拼音匹配按字符复用读音索引，避免在每个查询状态中重复查表，保持匹配和排序规则。
- SVG 预览的 Direct2D、D3D11 库限定从 System32 按需加载。
- 网络目录缓存验证完整头、记录数量与实际文件长度、完整文件名；损坏缓存不再提前分配大量条目。UNC 探测超时不读取尚未同步的耗时数据。
- 压缩包子进程只继承指定输入、输出句柄；限制运行库输出为 64 MiB，并在取消或超限时终止子进程。正常列表和解压逻辑不变。
- 自编译程序显式启用 CFG、ASLR 和 DEP。版本资源及发布脚本支持四段版本号。
- 免安装包包含 7-Zip 和许可证；打包前检查五个程序的版本，防止混入旧辅助程序。
- 文件和文件夹名称统一使用 DirectWrite、系统字体回退及 14 DIP 字号，统一普通名称、扩展名变色和搜索高亮的文字度量，并对齐垂直文字边界，改善中文名称的清晰度与稳定性。

# Pulse 1.0.5.6

本版包含当前工作区的资源状态解耦和内部接口收敛，保持既有界面、交互和搜索排序规则。

## 索引进程核实

2026-10-05 在当前安装实例核实到两个 `Pulse.Index.exe`：PID 5216 是 `PulseIndex` 服务（`--service`），PID 23996 是当前用户的 `--network-agent`。这是正常的职责分离，不是两个本地索引服务。网络共享使用当前用户会话的访问身份，本地服务使用机器服务身份。源码已在检测到服务安装时禁止再启动普通本地 helper，因此本次没有为了减少进程数量合并角色或修改启动逻辑。此次只读核实，没有重启或替换已安装服务。

## 功能与内部整理

- 状态、错误分类、取消和失败路径直接消费机器字段，显示文案只用于展示；详见 [资源解耦报告](../resource-decoupling-review.md)。
- 文件名联合搜索保留原比较器、分页与订阅，先排序候选引用，只复制输出页；菜单共用一个数据结构，删除重复 vector 分配和字段搬运。
- 生产 UI 不再编译网络索引执行源；排序枚举移到轻量契约头。详见 [行为保持优化报告](../architecture-preserving-optimization.md)。

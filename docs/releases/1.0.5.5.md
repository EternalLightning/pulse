# Pulse 1.0.5.5

本版整合文件管理器与界面更新，并修复合并后的交互、持久化和后台状态问题。

## 功能与修复

- 不可用的前进、后退按钮显示为灰色；快速连续导航和关闭标签页不再被双击消息吞掉。
- 修复右键菜单“以管理员身份运行”；库文件夹按本地化显示名称排序。
- 新增默认文件管理器设置、打开文件位置时选中文件、实验性 Explorer 窗口接管，以及登录到托盘、关闭最后标签时关闭窗口的选项。
- 改名项目保持原位和选中，新建项目追加到末尾；F5、切换排序和重新进入文件夹时重新排列。连续改名及通知回退保持正确位置和选择。
- 改善长路径、长名称和菜单文字的省略与全文提示；磁盘显示类型，缺失日期不再显示 1601 年。
- 新增 Pulse 自带菜单项与文件行按钮的显示设置；修复隐藏“更多”后长名称行的新标签按钮消失的问题。
- 侧栏滚动条随交互显隐；快速访问标记及直接设置的颜色持久化。
- 修复高级搜索与批量重命名输入框的显示和交互；完善文件占用反馈、重试、操作取消和撤销状态。
- 修复默认关联设置结果被覆盖、部分恢复失败和旧关联迁移问题；过期 Shell 选择请求不再激活错误标签。
- Shell 菜单与文件操作请求严格验证载荷，拒绝截断字符串、嵌入空字符和额外尾部数据；保留文件身份、关联所有权、传输认证及取消检查。

## 代码与测试整理

- 删除未用包装接口、只写不读字段、恒真缓存字段、重复的行按钮检查和文本截断实现。
- 可选 selftest 的专用实现仅在启用该选项时编入主程序；保留测试源码。
- 合并重复启动/关闭测试，删除旧独立夹具、重复链接脚本和过期构建绕行脚本；删除已被正式回收适配器替代的诊断实验，保留实际操作回归用例。
- 清除旧构建、1.0.5.4 发布暂存包、截图和测试产物；本次共清理 861 个生成文件、466,275,667 字节。生成数据和本机诊断不提交到源码仓库。

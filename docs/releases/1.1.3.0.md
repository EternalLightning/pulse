# Pulse 1.1.3.0

发布日期：2026-10-16。

安装载荷已更新至 `D:\Applications\Pulse`。对照构建将卡巴斯基告警缩小到新增操作恢复日志状态的生成代码；改为配置日志时才创建状态后，最终载荷和安装文件扫描均为零检测。归档结论与恢复入口见 [历史发布摘要](../history-summary.md#releases)。

- 修复加密压缩包内文件打开失败后仍缓存错误密码的问题。只有解压成功才保存密码；密码错误时清除对应缓存，下次打开重新询问，并提供密码错误或数据损坏的提示。
- 支持多个窗口。标签可拖出为独立窗口，跨窗口拖到标签栏或内容区可形成标签或分栏；拖动标题栏可合并整个窗口，分栏窗格也能单独拖出。分栏达到四个窗格时，跨窗口标签按独立标签保留。
- 在“设置 → 常规”增加“从其他程序打开文件夹”，可选择优先使用已打开的位置、新标签页或新窗口。
- 支持通过 Windows Shell 粘贴虚拟文件，包括远程桌面、压缩包及 Outlook 使用的虚拟文件格式。原有文件路径剪贴板与暂存托盘操作继续使用本地操作流程。
- 恢复日志状态按需创建，Shell 工作进程不再初始化应用窗口专用的多日志容器；保留多窗口日志隔离和启动恢复行为。

多窗口、外部打开和虚拟文件粘贴参考了上游项目的行为，针对本地代码实现：共享偏好设置、搜索历史、位置及图标缓存，各窗口保留独立的缩略图取消、目录工作线程和文件操作状态；操作日志按窗口隔离，启动时汇集遗留恢复记录。会话格式升级为版本 8，兼容旧单窗口记录。

验证结果及发布部署记录已归档，重要结论见 [历史发布摘要](../history-summary.md#releases)。真实远程桌面与 Outlook 会话、原生鼠标拖动和跨显示器 DPI 迁移尚未人工验收。

这是 EternalLightning 维护的 Pulse 独立发行版在本仓库的首次发布，基于 jimmgreen 及其贡献者开发的 [Pulse](https://github.com/jimmgreen/pulse)。

- 借鉴 Files 的界面设计，更新工具栏和窗格图标，调整菜单、对话框和滚动动画。
- 可自定义首页快捷访问卡片、工具栏按钮和快捷键。给常用文件夹设定别名后，在地址栏输入 `@work` 之类的别名即可跳转。
- 安装包和免安装版均内置正文搜索与压缩包支持，可查找 PDF、Office 文档等文件中的文字，也可浏览和解压 ZIP、7z 和 RAR。
- 文件对话框的 Shell 桥接和兼容接管可分别启用。调整了选择器的窗口层级，避免它弹在原生对话框后面。

上游版本差异、借鉴来源和许可证见 [README](https://github.com/EternalLightning/pulse/blob/v1.5.5.0/README.md)。

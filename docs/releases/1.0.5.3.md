# Pulse 1.0.5.3

## 界面与存储

- 新增 Home 首页，展示常用库、回收站、磁盘容量和网络位置；可在设置中选择新标签页打开首页，默认行为保持不变。
- 更新首页、已知文件夹与 OneDrive 图标，保留资源来源和许可证。
- 改进存储位置定位：迁移配置后删除旧目录不会丢失新位置，兼容导入旧版存储位置记录。
- 重复文件页统一为左侧标签/说明、右侧控件/动作布局；扫描位于最右，保留单选靠右，危险删除与普通操作区分，窄窗口与长文本支持换行。

## 删除安全

- Pulse 自有删除请求统一经过整批准入检查；永久删除显示不可逆原因、逻辑项目计数和路径摘要，默认取消，Esc/关闭取消。
- **重要行为变化：无法在执行前证明整批可回收时，整批停止，不试删、不自动退化为永久删除。当前普通 Delete、重复结果的回收删除，以及撤销复制/新建所需的回收删除都会受此限制。** 明确发起永久删除仍须确认。
- 取消不提前改变列表选择、预览、重复结果和保留项；预览删除使用请求专属目标，避免通过预览改变原列表多选。
- 未准入的 Undo/Recovery 保留原记录；不确定曾执行的删除不自动重放，保留精确恢复日志。恢复清理不再仅凭临时文件名模式递归删除。
- 私有删除 IPC 使用与 Shell 进程生命周期绑定的一次性计划；断管后不重发。准确区分逐项成功与跳过/失败，不以路径“消失”推断成功。
- 修复真实永久删除成功回调漏记：逐项接收器绑定确切授权根，正确处理 Shell 完成成功码，不在删除后重新解析已变动的 Shell 对象路径。

## 稳定性与验证

- 修复目录枚举 NT API 初始化竞态，以及枚举/采样/SHA-256 异常路径的资源释放。
- Windows 10/11 x64 Release 定向验证覆盖重复页布局/绘制/命中、删除确认与取消、预览事件顺序、恢复记录及真实专用文件/非空目录永久删除；保留既有配置与快捷键。
- 微测没有显示可靠性能提升，不宣称提速。真实多监视器 DPI 切换、任意第三方 Shell provider 和 Windows 8.1 未在本次本地发布验收中覆盖。
- 用户已手动检查 GUI；Debug GUI 的 D3D 调试层环境验收暂缓。本次先提供 Windows 10/11 x64 便携包；本地未提供 Inno Setup 编译器，安装包暂缓，也不发布 Windows 8.1 安装包。

第三方 Shell 扩展仍由外部程序执行，不在 Pulse 自有删除闸门保证范围；本版没有宣称解决文件路径替换 TOCTOU 或原子冻结整个批次。

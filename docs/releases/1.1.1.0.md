# Pulse 1.1.1.0

交付状态：已更新预览组件并重新核验完整载荷。首次预览 EXE 曾触发 Kaspersky 告警；共享内存 ACK 改用有效像素视图判断后，两组相关测试 43 PASS / 0 FAIL，本机对新构建及原安装位置扫描均未检出。没有提交复核或调整防护策略，不能保证未来云规则及其他环境的检测结果。详情见 docs/validation/1.1.1.0/antivirus-review.md。

本次不增加功能，修复菜单稳定性、清理确认无调用的退役代码，并纠正已有硬编码。

- 新建菜单取消“加载中…”占位，复用预加载会话；打开期间结构固定，晚到模板在下次打开时加入。
- 删除旧 Shell 重命名、回收站还原入口及不可达分支，保留当前身份校验、取消、失败传播和实际回收结果。
- 删除全库无调用的地址栏提示绘制、几何查询、标签调色板和索引包装接口。
- 默认导航回退使用实际 Windows 所在卷；产品版本、manifest 统一从 version.txt 生成。
- 文件操作、诊断导出、存储错误和 UNC 缓存年龄接入中英文资源，同一份文案支持资源和初始化前回退。
- 发布脚本目标改为当前发行仓库；安装器要求构建入口从 version.txt 传入版本。

本轮瘦身定向检查 209 PASS / 0 FAIL；前置菜单检查 93 PASS / 0 FAIL，渲染夹具 58 PASS / 0 FAIL。未执行完整历史回归、安装器安装或索引服务注册；真实第三方 Shell 模板、SMB/RaiDrive 和 UAC 成功授权仍需现场验收。

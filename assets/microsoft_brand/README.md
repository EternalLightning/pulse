# Microsoft product artwork

`onedrive.svg` is the unmodified Microsoft OneDrive product icon from the
[Microsoft Fluent/Fabric asset CDN](https://static2.sharepointonline.com/files/fabric/assets/brand-icons/product/svg/onedrive_48x1.svg), retrieved 2026-10-01.

[Microsoft Fabric Assets License Agreement](https://aka.ms/fluentui-assets-license),
included verbatim as `LICENSE.pdf`. It is not covered by the MIT license for
Fluent System Icons. Pulse displays it only alongside detected OneDrive account
folders to identify and open that Microsoft service's synchronized files.
The artwork, colors and aspect ratio are unchanged.

Files uses the local OneDrive executable's icon rather than an SVG:
[CloudDrivesDetector.cs](https://github.com/files-community/Files/blob/main/src/Files.App/Utils/Cloud/CloudDrivesDetector.cs).
